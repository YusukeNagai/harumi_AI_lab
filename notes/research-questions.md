## 問い5：参加費をいくらにするか

会場のルールの中で、近所の相場と比べて、いくらなら申し込みやすいか。

| 何を調べるか | リサーチ |
|---|---|
| 会場ごとのお金のルール：はるみらいの育成サポーター制度の謝礼の目安（1組3,000円）の扱い、HARUMI FLAGの共用施設で「非営利」とされる範囲 | T-29（分からない点はT-04のメールで聞く） |
| 近所の相場：地域の体験会・ワークショップ、公共施設の講座、民間教室の体験会 | T-28 |
| 子ども向けAI・プログラミング教室、オンライン講座の料金と、1回あたりの人数 | T-23 |
| 保護者が払ってもよいと思う額 | T-24、T-28 |

使う判断：T-11（参加費）

検討のメモ（案）：
- 少人数で高めにすると、感想が深くなりやすく、学年の幅にも対応しやすい。実績のない第1回では集まりにくく、会場のルールと合わない可能性がある。
- 多めの人数で安めにすると、集まりやすい。講師1人では目が届きにくく、あとから値上げもしにくい。
- 人数は問い4で決まる上限に合わせ、参加費は会場の目安に近い額にして、アンケートで「いくらなら続けて来たいか」を聞く形も考えられる。

| 何を調べるか | リサーチ |
|---|---|
| 晴海の子どもの人数と年齢構成、ファミリー層（中央区の統計など） | T-27 |
| 晴海にすでにある子ども向けの活動や団体 | T-27 |
| 晴海・湾岸エリアの近くの教室と、自治体や図書館の無料講座（保護者がほかに何を選べるか） | T-23 |
| 子ども向けAI教育の市場（保護者の関心が高まっているか） | T-24 |
| 告知の手段：SNS、地域の掲示板やLINEのグループ、イベント告知サイト、学校を通じたチラシ配布のルール | T-32 |
| 人の集め方の例：地域の子ども向け教室や体験会が、初回の参加者をどう集めたか。うまくいった方法と、手間に見合わなかった方法 | T-32 |
| 申込みにつながる告知の中身：決め手になる情報（日時、場所、参加費、持ち物、講師、安全の説明など）、告知を始める時期と締切までの期間 | T-32 |

使う判断：T-16（人の集め方）、T-19（告知と申込みフォーム）、T-20（チラシ）
