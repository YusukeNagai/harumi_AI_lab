## 問い3：「少人数・高め」と「多め・安め」のどちらで始めるか

第1回を、少人数で参加費を高めにして始めるか、多めの人数で安めにして感想をたくさん集めるか。

| 何を調べるか | リサーチ |
|---|---|
| 会場ごとのお金のルール：はるみらいの育成サポーター制度の謝礼の目安（1組3,000円）の扱い、HARUMI FLAGの共用施設で「非営利」とされる範囲 | T-29（分からない点はT-04のメールで聞く） |
| 近所の相場：地域の体験会、公共施設の講座、民間教室の体験会の参加費 | T-28 |
| 近くの子ども向けAI・プログラミング教室の料金と、1回あたりの人数 | T-23（この2点だけに絞る） |
| 講師1人で見られる人数。端末やWi-Fiの用意で、その人数がどう変わるか | T-31、T-29、T-30 |
| 保護者が払ってもよいと思う額 | T-24、T-28 |

使う判断：T-10（場所）、T-11（参加費）、T-12（定員・機材）

検討のメモ（案）：
- 少人数・高めは、感想が深くなりやすく、学年の幅にも対応しやすい。一方で、実績のない第1回では集まりにくく、会場のルールと合わない可能性がある。
- 多め・安めは、集まりやすく、つながりの場という目的にも合う。一方で、講師1人では目が届きにくく、感想が浅くなりやすい。あとから値上げもしにくい。
- 感想の深さは、金額より人数と聞き方で決まる面が大きい。「少人数×会場の目安に近い参加費」にして、アンケートで「いくらなら続けて来たいか」を聞く形も考えられる。

## 問い4：晴海の保護者にどう届け、どう人を集めるか

晴海に対象の子どもはどれくらいいて、その保護者はどこで地域の情報を見ているか。
実績のない第1回で、どうやって参加者を集めるか。告知はどこに力を入れるか。
保護者は子どものAI利用に何を期待し、何を心配しているか（告知の文面に使う）。

| 何を調べるか | リサーチ |
|---|---|
| 晴海の子どもの人数と年齢構成（中央区の統計など） | T-27 |
| 晴海にすでにある子ども向けの活動や団体 | T-27 |
| 告知の手段：SNS、地域の掲示板やLINEのグループ、イベント告知サイト、学校を通じたチラシ配布のルール | T-32 |
| 人の集め方の例：地域の子ども向け教室や体験会が、初回の参加者をどう集めたか（口コミ、知り合いの紹介、公共施設の掲示、事前登録、無料体験など）。うまくいった方法と、手間に見合わなかった方法 | T-32 |
| 申込みにつながる告知の中身：申込みの決め手になる情報（日時、場所、参加費、持ち物、講師、安全の説明など）、告知を始める時期と締切までの期間 | T-32 |
| 保護者の関心と不安 | T-24（問い1と共用） |

使う判断：T-16（人の集め方）、T-12（定員の見込み）、T-19（告知と申込みフォーム）、T-20（チラシ）
