- 初回で定員に届かなかった例が2件ある。20組の定員に6組、10世帯の想定に4世帯（`notes/trial-programs.md` #1・#12、`notes/outreach.md`）。
- 初回は、広く募集するより知り合いに直接声をかけたほうが集まりやすい。1回の告知で申し込む人は少ないので、何度も目に触れるようにする（`notes/outreach.md` の解説記事。実例ではない）。
- 晴海西小・中だけで小中学生が約1,500人いる。住民の45%が晴海五丁目（HARUMI FLAG）に住んでいる（`notes/harumi-area.md`）。遠くまで広げなくても、近所に何度も届ければ足りると考えた。

## Instagramの運用

- ペース：ゆっくり。無理のない回数（月2〜4回ほど）で続け、フォロワー数の目標は置かない。
- 写真などの素材：永井が用意する。
- 月に1回、Claude Code が1か月分（2〜4投稿）の画像と投稿文・ハッシュタグを作り、フォルダに置く。画像はチラシと同じ見た目にそろえる。
- 永井が Instagram のアプリで、まとめて予約投稿する。コメントへの返事も永井。Claude Code は投稿もログインもしない。
- 自動で投稿する仕組み（開発者向けの機能）は使わない。外に出る操作は、必ず永井が確かめてから出す。
- 載せるもの（案）：永井がAIで作ったお手本の作品、準備の様子、保護者向けの短い話（子どもがAIを使うときの約束、年齢条件など。`notes/ai-rules.md` が材料）。
- 子どもの作品は、第1回のあと、保護者の了承が取れたものだけ。子どもの顔、名前、学校名は載せない。
- 投稿の下書きを置く場所は、公開リポジトリに置いてよいか（公開前の投稿が見えてしまう）を含めて、最初の投稿を作るときに決める。
- まだ確かめていないこと：予約投稿の今の条件（アカウントの種類、何日先まで予約できるか）。
