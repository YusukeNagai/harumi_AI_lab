# 子どもへのAIの提供の形（T-26・途中版）

- 確認日：2026-10-22
- 状態：**途中版**。公式ページで分からない点が多く、各社への問い合わせが必要。
- 答える問い：問い1（小学1年生でも使えて、講師が管理できるAIツール）、問い2（年齢条件と保護者同意）。詳しくは `notes/research-questions.md`。
- 決めるのは永井。ここでは比べるだけにする。

## 結論

- 子どもが直接さわれて、講師が会話の中身を見られるツールはある（スクールAI、SchoolAI など）。
- ただし、小学生が使ってよいか、民間の教室でも契約できるかは、どれも公式ページだけでは分からなかった。
- 13歳未満が自由に文章で話せる既製ツールで、規約上はっきり使ってよいと書かれたものは、まだ見つかっていない。
- 今回見た範囲では、子どもが直接使うツールは**勉強のサポート用**（分からない問題を聞く、英会話、作文の手直し）が中心。**作品づくり向けは少ない**。

## 目的で分けると

| 目的 | ツール |
|---|---|
| 勉強のサポート | スタディポケット、スクールAI、SchoolAI、MagicSchool |
| 考える力の練習 | LOGIQ LABO |
| AIのしくみを知る | Code.org、Teachable Machine |
| 作品づくり | Canva Education（学校向け） |

スクールAI や SchoolAI は「先生がAIの使い方を決めて子ども用の場をつくる」作りなので、物語づくり用の場をつくれる可能性がある（未確認）。

## AI各社の条件（二次ツールの前提）

AI各社が、自社のAIを子ども向けサービスに組み込むことを認めているかは `notes/ai-rules.md` の「4」にまとめた。要点は次のとおり。

- Anthropic（Claude）とOpenAIは条件つきで認めている。
- Google（Gemini API）は禁止している。
