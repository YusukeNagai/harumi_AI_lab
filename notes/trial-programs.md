## 結論

国内の公開例を17件集めた。作品づくりの会は2時間前後が多く、持ち帰りは「その場で印刷」がいちばん多い。印刷はA4カラーで1枚50〜60円ほどで、費用も手間も小さい。講師1人で見られる人数は、子どもだけなら4〜6人がよく挙がる目安で、8人を超えると待ち時間が増えるとされる。第1回の候補として、絵本、缶バッジ、学年で分ける形の3つを「案」として最後に置いた。

## 31-3 小1・2でもできる内容と、保護者同伴

**小1・2でもできた内容**
- AIでつくった絵を印刷して、手で塗る・飾る（#1、#3）。
- 子どもは紙に一言書くだけで、入力は大人がする（#5）。
- 絵本は、主人公・舞台などを紙のシートに書いてから、AIでつくる（#7）。

**低学年での注意（JSTの教材の手引き）**
- 1・2年生は、先生がAIを操作し、子どもは出てきた結果を見て話し合う形をすすめている。

**運営の振り返り（#1）**
- 1時間は短かった。
- 親子の作業の分担を決めておけばよかった。
- アカウント作りや音声入力は前もって説明が要る。
- 色鉛筆やかご、掃除道具の準備が必要。

**保護者同伴の扱い**
| 扱い | 例 |
|---|---|
| 親子で一緒に参加 | #1、#3、#4、#6、#11、#12（低学年を含む会はほぼこの形） |
| 同伴が必須 | #10（保護者1人）、#13、Gemini Camp |
| 子どもだけ参加。保護者は見学のみ | #9、#15（どちらも東京都の施設。小4以上） |
| 同席は自由 | #17（オンライン） |

## 31-6 はるみAIラボ第1回の候補（案）

ここからは**案**。決めるのは永井（T-07、T-09）。

**前提**
- 13歳未満は ChatGPT・Gemini などを自分のアカウントで使えない。Claude の個人向けは18歳以上（`notes/ai-rules.md`）。
- 小1〜小6が直接さわれて規約上はっきり使えるツールは、まだ見つかっていない（`notes/ai-tools.md`）。小学生は「子どもが考えて伝え、講師の端末でAIを動かす」形を基本にする。
- 晴海西小・中だけで小中学生は約1,500人いる（`notes/harumi-area.md`）。人数より、講師1人で見られる範囲が上限になる。

| | 案A 絵本 | 案B キャラクター缶バッジ | 案C 学年で分ける |
|---|---|---|---|
| 対象 | 小1〜中学生、親子で参加 | 小1〜中学生、親子で参加 | 小学生の回と、中学生の回を分ける |
| 時間 | 90分 | 90分 | 各90分 |
| つくるもの | ワークシートに主人公・場所・できごとを書き、AIで絵と文にする | 好きなもの2つを組み合わせたキャラクターをAIで絵にする | 小学生：案Aか案B。中学生：保護者の同意を得て、本人のアカウントでかんたんなゲームやクイズをつくる |
| 学年の幅への対応 | 小1・2は絵と一言で1ページ。高学年・中学生は数ページの物語 | 小1・2は絵だけ。高学年・中学生は性格や設定も考えてプロフィールカードにする | 回ごとに内容をそろえられる |
| AIを動かすのは | 講師の端末（小学生）。中学生は本人が操作してもよい（年齢条件しだい） | 講師の端末 | 小学生は講師の端末。中学生は本人 |
| 持ち帰り | 印刷した絵本（ホッチキスでとめる） | 缶バッジと、印刷した絵 | 小学生：印刷物か缶バッジ。中学生：ゲームのQRコード |
| 人数の目安 | 親子6〜8組 | 親子6〜8組 | 小学生の回：親子6〜8組。中学生の回：4〜6人 |
| 費用の目安 | 印刷代（1人数百円以内） | 機械を借りる代金とパーツ代 | 回が2つになる分、会場代と手間が増える |
| 参考にした例 | #1、#5、#7 | #9（キーホルダーをバッジに変えた形） | #8（メニューを選ぶ形）、#15 |

- どの案でも、AIの誤り、個人情報、著作権を短く扱う（CLAUDE.md の安全のルール）。
- 人数の目安は 31-5 の目安と、親子参加で保護者が手伝う前提で置いた数（案）。
